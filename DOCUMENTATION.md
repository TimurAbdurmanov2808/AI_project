# Техническая документация: Система модерации жестов

## Описание проекта

Система автоматической модерации жестов в реальном времени — программный комплекс, предназначенный для обнаружения оскорбительных жестов руками через веб-камеру. Система анализирует видеопоток, определяет положение руки и классифицирует жест как нейтральный или оскорбительный.

**Область применения:** модерация видеозвонков, онлайн-трансляций, видеоконференций и образовательных платформ.

---

## Используемые технологии

### Python 3.12
Основной язык разработки. Выбран за развитую экосистему библиотек машинного обучения и компьютерного зрения, простоту прототипирования и кроссплатформенность.

### MediaPipe 0.10.35
Фреймворк компании Google для обработки медиаданных. В проекте используется модуль `Hand Landmarker` — нейросетевая модель, которая в реальном времени находит руку на изображении и возвращает координаты 21 ключевой точки (суставы и кончики пальцев). Каждая точка представлена тремя координатами (x, y, z), итого 63 признака на один кадр.

### OpenCV 4.13
Библиотека компьютерного зрения. Используется для захвата видеопотока с веб-камеры, обработки кадров, отрисовки визуальных элементов на экране (статус, рамки, подписи) и преобразования цветовых пространств (BGR → RGB для MediaPipe).

### scikit-learn 1.8
Библиотека машинного обучения. В качестве классификатора используется `RandomForestClassifier` — ансамблевая модель из 100 деревьев решений. Также используются инструменты оценки качества: `train_test_split`, `cross_val_score`, `accuracy_score`, `f1_score`.

### NumPy 2.4
Библиотека для работы с числовыми массивами. Используется для хранения и обработки векторов признаков (координат ключевых точек), формирования обучающей выборки и передачи данных между компонентами системы.

### Matplotlib 3.10
Библиотека визуализации данных. Используется для построения графика уверенности модели по итогам тестовой сессии — показывает как менялась вероятность оскорбительного жеста во времени.

## Архитектура системы

```
Веб-камера
    │
    ▼
HandDetector (MediaPipe)
    │  21 точка руки → 63 координаты (x, y, z)
    ▼
GestureClassifier (RandomForest)
    │  вероятность offensive / neutral
    ▼
GestureModerationEngine
    │  буферизация 8 кадров → финальное решение
    ▼
Результат: is_obscene (bool) + confidence (float)
```

### Исполнитель 1 — Библиотека `gesture_moderation`

**Полная ответственность за Python-пакет** — ядро всей системы, которое используют остальные участники.

**Файлы:**
- `проектЦК/gesture_moderation/__init__.py`
- `проектЦК/gesture_moderation/core/detector.py`
- `проектЦК/gesture_moderation/core/classifier.py`
- `проектЦК/gesture_moderation/core/engine.py`
- `проектЦК/gesture_moderation/utils/trainer.py`
- `проектЦК/gesture_moderation/utils/augmentations.py`
- `проектЦК/gesture_moderation/utils/data_collector.py`
- `проектЦК/setup.py`

**Задачи:**
- Реализация `HandDetector` — детекция руки через MediaPipe, извлечение 63 координат
- Реализация `GestureClassifier` — загрузка обученной модели, предсказание класса и вероятности
- Реализация `GestureModerationEngine` — объединение детектора и классификатора, буферизация кадров, финальное решение
- Реализация `ModelTrainer` — загрузка данных, обучение RandomForest, кросс-валидация, сохранение модели
- Оформление пакета: `__init__.py`, `setup.py`, экспорт публичного API

### Исполнитель 2 — Сбор и подготовка датасета

**Файлы:**
- `collect_data.py`
- `dataset.csv`

**Задачи:**
- Разработка скрипта сбора данных с веб-камеры в реальном времени
- Реализация логики удержания жеста (0.5 сек) для стабильной записи
- Формирование структуры CSV: 63 координаты + метка класса
- Сбор датасета: не менее 400 примеров класса `offensive` и 400 примеров класса `neutral`
- Контроль баланса классов, обеспечение разнообразия поз и условий съёмки

**Итог работы:** файл `dataset.csv` с ~800+ размеченными примерами, готовый к обучению.
